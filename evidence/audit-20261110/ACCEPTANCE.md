# Предварительные критерии — 2026-11-10

База: `455106542aa610635c2e01c05a11d214c94a611d`. Зафиксировано после
первого baseline (18 наборов, 162 сочетания), до изменения production C.
До настройки дополняем фиксированный корпус 16-символьным шумом,
длинными общими префиксами и доступным JPEG/его BGRA-пикселями.
Исходники pagezip/pz01, zeros, periodic, small_alphabet и long_prefixes — tuning;
остальные — отдельная validation-часть. Имена/seed не участвуют в кодеке.

1. Обязательны корректность, прежние API/ABI и чтение прежнего wire.
   Для сокращения поиска требуем **побайтно тот же encoded output** на всём
   фиксированном наборе и отдельном differential/property прогоне.
2. PZ01 не меняем без отдельного измеренного основания. PZ02, PZ03 и PZA:
   полный размер не увеличивается ни на одном входе, включая RAW и metadata.
3. Общий режим принимается при улучшении целевой стоимости encode >=10%,
   геометрическом среднем отношения времени <=1.05 для затронутых режимов
   на validation и без отдельной регрессии encode/decode >20%.
   При провале критериев откатываем только собственный эксперимент; новый
   порог ради результата не назначаем. Все положительные регрессии публикуем.
4. Нет heap, межстраничной истории или внешнего движка в page-библиотеке.
   Локальный порог эксперимента: рост отдельного stack frame <=256 байт,
   суммарного `.text` page-объектов <=512 байт. Это **критерии аудита**,
   не выдуманный контракт проекта. Реальные baseline frames: page_pack=6648,
   pz03_page_pack=4296, pza_pack=4232 байт при данном LLVM/Windows ABI.
   Вложенные вызовы прибавляют стек; это не RAM процесса.
5. Исправление отказа public pza_unfilter на успешном pza_filter обязательно;
   допустимы минимальные расходы проверки диапазона. Page wire limits неизменны.
6. Timebox: каждый performance-эксперимент <=15 минут; sanitizer/fuzz <=5 минут
   на сборку/прогон; первоначальный libFuzzer прогон 60 секунд с фиксированным
   seed. При подтверждённом новом дефекте отдельный timebox на его устранение.
7. Host/solid не оптимизируется в этом Windows-эксперименте. Его Linux/POSIX
   зависимости, fsync и результаты не приписываются встроенным кодекам.

Пять измеряемых батчей после прогрева, baseline/candidate чередуются в одном
Python-процессе; время снимается внутри C, >=8ms целевая длительность батча.
Числа имеют системный шум, изоляции CPU нет. RAW PZ включает 16 байт на страницу;
LZ4 без framing/checksum, Zstd frame без checksum, zlib с Adler32.
